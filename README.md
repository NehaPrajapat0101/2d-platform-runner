# Unity 2D Platformer Prototype

A Unity 2D platformer prototype developed to practice gameplay programming and Animator state machines.

## Features

- Character movement
- Walk and Run
- Jump
- Crouch
- Weapon Equip/Unequip
- Blend Tree Locomotion
- Animator State Machine
- Sprite Direction Flip

## Built With

- Unity
- C#

## Controls

| Key | Action |
|------|--------|
| A / D | Move |
| Left Shift | Run |
| Space | Jump |
| Left Ctrl | Crouch |
| Q | Equip / Unequip Gun |
